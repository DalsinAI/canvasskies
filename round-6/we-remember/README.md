# We Remember

The roll at the very end of the game, on Lab-51 (GFOS), at 1x.

`we-remember-preview.webp` is 84 seconds of the scene, captured twice a
second and shown at four times speed. `remember-wind.wav` is its only sound.
The names in these captures are made-up examples, used only to test the
scene; the released file has none.
